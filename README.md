# unli-photos

Auto-sync media to Google Photos with Google Pixel unlimited spoofing, powered by
[`gotohp-cli`](https://github.com/xob0t/gotohp). A clean, professional Textual TUI
rewrite of the [GoogleUnlimited](https://github.com/shishir0x/GoogleUnlimited)
orchestration concept for Linux.
